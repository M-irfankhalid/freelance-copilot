# Agent Instructions

## Before coding

1. Read CLAUDE.md.
2. Read DEVELOPMENT_PLAN.md.
3. Identify the current development phase.
4. Inspect the existing code before changing it.
5. Reuse existing patterns.

## While coding

1. Keep changes small.
2. Do not add unnecessary dependencies.
3. Do not introduce new architecture without a reason.
4. Keep frontend and backend responsibilities separated.
5. Keep secrets out of source code and logs.
6. Follow existing naming and folder conventions.

## After coding

1. Run type checking.
2. Run linting.
3. Run relevant tests.
4. Fix errors caused by the changes.
5. Report what was implemented.

## Important

Do not silently skip requirements.

Do not mark a phase complete when its core functionality is not working.

If something is unclear, inspect the project first and make the smallest reasonable decision.
